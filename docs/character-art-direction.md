# Characters gallery illustration direction

Use the existing watercolor paintings as the rendering reference: warm ivory paper, soft detailed watercolor, 3:2 landscape, 1100 × 733 WebP. The website supplies the Chinese glyph and pinyin. Keep identifying features large and in the upper part of the center square so the gallery crop and lettering preserve them.

Each image needs its own semantic feature, subject framing and, where relevant, action. A different face or a different color alone is insufficient. Avoid adding the same mountains and trees behind unrelated subjects.

| Related cards | Visible distinction |
| --- | --- |
| 河 / 江 / 湖 / 海 | 小河: winding channel with close banks; 长江: broad directional bend; 湖: still water enclosed by land; 海: open horizon |
| 波 / 浪 | Small circular surface ripples / a large curling breaking wave |
| 冰 / 冷 | Solid faceted ice / a visibly cold person huddled in a scarf |
| 日 / 光 / 阳 / 晴 | Sun disk / visible light beam / a sunlit slope / clearly cloudless weather |
| 木 / 林 / 森 / 树 | Trunk and roots / small grove / dense forest interior / a large tree seen from its trunk |
| 我 / 你 / 他 / 她 | Self-pointing / directly addressed person / a third male person / a third female person |
| 兄 / 弟 / 姐 / 妹 | The relevant older or younger sibling is the clear focal figure, with a different concrete interaction |
| 家 / 屋 / 房 / 室 / 厅 | Family at home / house exterior / bedroom / classroom layout / living room |
| 门 / 开 / 关 | A door as an object / lifting a box lid open / lowering a box lid closed |
| 米 / 饭 / 面 / 汤 / 碗 | Dry loose grains / cooked rice mound / lifted noodle strands / liquid broth / an empty bowl |
| 来 / 去 | Approaching the viewer / moving away in rear view |
| 本 / 张 / 块 / 只 | A selected bound book / one held flat sheet / a separated chunk / one countable cat |

Scenes illustrate the taught meaning or example, rather than define all uses of a character. Closely related meanings can be distinguished through a different relevant context; do not invent a dictionary distinction to justify a picture.

Number cards use different countable arrangements or identifying forms, not a repeated apple composition. Check counts visually before accepting them. Time-related cards use different characteristic objects or situations, rather than a wall clock on every card.

The prompt set is `character-art-prompts.json`. Explicitly revised briefs carry `artRevision` and `distinctiveFeature`; a higher revision also gives the image a fresh URL. `character-art-manifest.json` records the revision actually installed. Preserve the existing original paintings when a new gallery-specific variant can express the intended distinction.
